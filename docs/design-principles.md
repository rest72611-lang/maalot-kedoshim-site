# עקרונות עיצוב: האתר הציבורי של מעלות קדושים

המסמך קובע איך האתר הציבורי נראה ומתנהג, כדי שכל שינוי עתידי ישמור על שפה אחת. **ממשק הניהול לא כפוף למסמך הזה**: שם מה שקובע הוא בהירות, אבטחה ונגישות.

**השראה:** המבנה וקצב הסקשנים של אתרי בתי כנסת מוכרים, ובעיקר נהר שלום. **לא מעתיקים** קוד, גופנים, לוגו, צבעים, טקסטים או תמונות של אף אתר. הזהות של מעלות קדושים סגולה.

---

## 1. עקרונות

1. **קודם תוכן:** זמני תפילות, מודעות ותרומה צריכים להיות קלים למציאה מכל מסך.
2. **זהות סגולה:** הסגול הוא הצבע הדומיננטי. הצבע החם משמש לפעולה, כמו תרומה ומעבר לעמוד.
3. **קצב ברור:** הסקשנים מתחלפים ברקע (שמנת, לבן, פס סגול), עם כותרת סקשן בולטת.
4. **קל ומהיר:** בלי ספריות JavaScript ובלי כלי מעקב. הגופן מאוחסן באתר עצמו, ותמונות עוברות אופטימיזציה בבנייה.
5. **נגיש מההתחלה:** HTML סמנטי, ניגודיות AA, ניווט מלא במקלדת, ותמיכה ב־`prefers-reduced-motion`.
6. **מתחילים מהמובייל:** כל רכיב נבדק קודם ברוחב 360px, ואחר כך ב־768 וב־1280.

## 2. Design tokens

כל הערכים מוגדרים כ־CSS custom properties ב־`src/styles/site.css`, בסעיף 1 ובשכבה 15. משתמשים רק בהם, ולא בערכים קבועים בקוד.

| קבוצה | Token | ערך | שימוש |
|---|---|---|---|
| צבע | `--color-primary` | `#4c2451` | כותרת עליונה, פסי סקשן, כפתור ראשי |
| | `--color-primary-dark` | `#3a1a3e` | footer, hover |
| | `--color-accent` | טרקוטה | הדגשה ופעולה |
| | `--color-bg` / `--color-surface` / `--color-band` | שמנת / לבן / סגול בהיר | חילופי רקע בין סקשנים |
| | `--color-on-primary` | `#fbf7f0` | טקסט על סגול |
| טיפוגרפיה | גופן | **Heebo** (OFL-1.1, משקל משתנה, Hebrew ו־Latin בלבד) | כל האתר |
| | גוף | `1.0625rem`, line-height כ־1.6 | |
| | כותרות | בעזרת `clamp()` ובקנה מידה רציף | h1 גדול, h2 בין 1.5 ל־2.25rem |
| ריווח | `--space-1` … `--space-6` | סולם של 0.25rem | בתוך רכיבים |
| | `--space-section` | `clamp(3rem, 2rem + 4vw, 5.5rem)` | בין סקשנים |

| | כפתורים | `0.75rem`, גובה מינימלי 48px | |

## 3. רכיבים

| רכיב | כלל |
|---|---|
| **כותרת עליונה** | פס סגול, לוגו בעיגול לבן ושם האתר, 3 קישורים. העמוד הפעיל מסומן גם בלי צבע (`aria-current` + קו). תרומות בצבע ההדגשה |
| **כותרת סקשן** | "לשונית" סגולה שמחוברת לקצה העליון של הסקשן. בעתיד יתווסף קישור "לכל…" |
| **כפתור ראשי** | רקע סגול וטקסט בהיר. hover כהה יותר. focus עם מסגרת חיצונית |
| **כפתור משני** | מסגרת סגולה, רקע לבן |
| **כרטיס** | רקע לבן, `--radius-card`, צל רך ויחס תמונה קבוע (`aspect-ratio`) כדי למנוע קפיצות בטעינה (CLS) |
| **קרוסלה** (P7.3) | `scroll-snap` עם JS קטן, בלי ספרייה. כפתורי קודם/הבא וכפתור עצירה. מקלדת ומגע. בלי תנועה אוטומטית ב־`prefers-reduced-motion` |
| **פופאפ** (P7.6) | תמונה אחת, `<dialog>`, נפתח פעם אחת למבקר וניתן לסגירה ב־Esc |
| **Footer** | סגול כהה. שם, זכויות וקישור לתרומה. **בלי טלפון** (החלטה Q16) |

## 4. נקודות שבירה

| רוחב | מה משתנה |
|---|---|
| עד 47.99rem (מובייל) | תפריט המבורגר; עמודה אחת; כפתורים ברוחב מלא |
| 48rem ומעלה | ניווט מלא בשורה; גרידים של 2–3 עמודות |
| מיכל | רוחב מקסימלי של כ־72rem |

## 5. מה לא עושים

- לא מוסיפים כלי מעקב, jQuery או ספריות קרוסלה.
- לא מוסיפים כפתורים צפים או וידאו ב־Hero.
- לא טוענים גופנים מ־Google או מ־CDN. הכל מאוחסן באתר.
- לא משתמשים בצבע בלבד כדי להעביר מידע.
