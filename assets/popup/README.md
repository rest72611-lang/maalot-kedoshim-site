# תיקיית מודעות הפופאפ

תיקייה זו היא המקור היחיד למודעות שמוצגות בחלון הפופאפ שנפתח אוטומטית בדף
הבית.

## אילו קבצים נתמכים

כל קובץ מסוג `.pdf` (גם `.PDF`, לא תלוי אותיות גדולות/קטנות) שנמצא **ישירות**
בתוך התיקייה הזו נטען אוטומטית כמודעה. קבצים מסוגים אחרים ותיקיות משנה
מתעלמים מהם.

כל PDF הופך למודעה אחת בפופאפ, על בסיס **העמוד הראשון בלבד** שלו.

## איך מוסיפים מודעה

1. מעתיקים את קובץ ה־PDF החדש לתוך `assets/popup/`.
2. מריצים `npm run build`.

זהו — אין צורך לשנות שום קובץ קוד, HTML או CSS.

## איך מסירים מודעה

1. מוחקים את קובץ ה־PDF המתאים מתוך `assets/popup/`.
2. מריצים `npm run build`.

## איך קובעים את סדר ההופעה

סדר המודעות נקבע לפי **שם הקובץ**, במיון טבעי (כלומר `2.pdf` יופיע לפני
`10.pdf`). מומלץ להשתמש בקידומת מספרית לשליטה נוחה בסדר, למשל:

```text
01-rosh-hashana.pdf
02-selichot.pdf
03-special-notice.pdf
```

כדי לשנות את הסדר — פשוט משנים את שם הקובץ ומריצים build מחדש.

## לאן נכתבות התמונות

ה־build הופך כל PDF לתמונת PNG (העמוד הראשון בלבד) ושומר אותה בתוך:

```text
dist/assets/popup/
```

תיקיית `dist` נוצרת אוטומטית בכל build, ולכן **אסור לערוך אותה ידנית** —
כל שינוי ידני שם יימחק בהרצה הבאה.

## חשוב לזכור

לאחר כל הוספה, הסרה או שינוי סדר — יש להריץ:

```bash
npm run build
```

כדי שהשינוי יופיע בפועל באתר.
